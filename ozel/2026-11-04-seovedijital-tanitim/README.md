# SeoveDijital tanıtım reels (özel kurgu, 30 sn, 1080×1920)

Kurgu: kanca (Google / Trendyol / yapay zeka arama çubukları, "Müşteriniz sizi nerede arıyor?" → "Her yerde görünür olun.")
→ SeoveDijital marka açılışı → telefonda canlı ana sayfa turu (hero + ücretsiz ön analiz, hizmet sekmeleri AI GEO / SEO / Trendyol yatay kaydırma,
"Müşteriniz nerede arıyorsa", süreç adımları, örnek ön analiz skoru, Trendyol kâr paneli, kullandığımız araçlar) → kapanış (seovedijital.com, telefon).

- `python3 sayfa.py 1-header.html 2-anasayfa-icerik.html 3-footer.html` (proje dosyaları `seovedijital-anasayfa/`) → `sayfa.html`
- `ozel/` klasöründe `python3 -m http.server 8767`, sonra bu klasörde `NODE_PATH=/opt/node-tools/node_modules node rend.js test 3 9 16` ya da `node rend.js full` → `video.mp4`
- `python3 muzik.py` → `muzik.wav`; birleştirme ve kapak komutları `../2026-11-04-trendyol-kar-araci/README.md` ile aynı.
